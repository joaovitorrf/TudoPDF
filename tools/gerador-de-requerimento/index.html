Perguntas Frequentes

É um pedido formal por escrito dirigido a uma autoridade, instituição ou empresa — como segunda via de documentos, revisão de nota, transferência de escola, entre outros.

O comum é usar "Ao(À) [cargo] de [instituição]", como "Ao Diretor da Escola X" ou "À Secretaria de Recursos Humanos da Empresa Y".

Não é sempre obrigatório, mas uma boa justificativa aumenta as chances do pedido ser atendido — o campo é opcional.

Sim, o modelo segue a estrutura formal padrão usada tanto para órgãos públicos quanto para instituições privadas.
